## 1. Manual Calculation (for one query)

Let's manually compute metrics for the apple example.

```python
# Example data for ONE query
retrieved_chunks = ["Chunk B: Oranges are orange...", 
                    "Chunk A: Apples are red or green...", 
                    "Chunk C: Bananas are yellow..."]
# Ground truth: Only Chunk A is relevant (index 1 in zero-based list)
relevant_indices = {1}  # position of Chunk A

# LLM answer
generated_answer = "Apples are red or green, and they are delicious."

# Ground truth answer (for correctness)
true_answer = "Apples are red or green."

def manual_metrics(retrieved, relevant_indices, k=3):
    # Hit@k
    hit = 1 if any(i in relevant_indices for i in range(min(k, len(retrieved)))) else 0
    
    # MRR
    mrr = 0
    for rank, idx in enumerate(range(min(k, len(retrieved))), start=1):
        if idx in relevant_indices:
            mrr = 1/rank
            break
    
    # Precision@k
    retrieved_relevant = sum(1 for i in range(k) if i in relevant_indices)
    precision = retrieved_relevant / k if k > 0 else 0
    
    # Recall@k (total relevant = 1 in this case)
    recall = retrieved_relevant / len(relevant_indices)
    
    return hit, mrr, precision, recall

hit, mrr, precision, recall = manual_metrics(retrieved_chunks, relevant_indices, k=3)
print(f"Hit@3: {hit}")          # 1
print(f"MRR: {mrr}")            # 0.5 (since correct at position 2)
print(f"Precision@3: {precision:.2f}")  # 0.33
print(f"Recall@3: {recall}")    # 1.0

# Faithfulness – check if all facts in answer are in retrieved chunks
# We'll do a simple keyword check (real faithfulness uses LLM)
retrieved_text = " ".join(retrieved_chunks)
answer_facts = ["red or green", "delicious"]  # split simplistically
faithful = all(fact in retrieved_text for fact in answer_facts if fact != "delicious")
print(f"Faithfulness (simple): {faithful}")  # False because "delicious" not in retrieved
```

**Output:**
```
Hit@3: 1
MRR: 0.5
Precision@3: 0.33
Recall@3: 1.0
Faithfulness (simple): False
```

## 2. Using RAGAS (Proper, Scalable, LLM-based)

RAGAS uses an LLM (e.g., GPT-4) to judge faithfulness, answer relevance, etc. It's the standard for production evaluation.

### Installation

### Full Example with Sample Dataset

```python
import pandas as pd
from datasets import Dataset
from ragas import evaluate
from ragas.metrics import (
    faithfulness,
    answer_relevancy,
    context_precision,
    context_recall,
    context_relevancy
)
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from ragas.llms import LangchainLLMWrapper
from ragas.embeddings import LangchainEmbeddingsWrapper

# ==========================================
# 1. Prepare your evaluation dataset
# ==========================================
# Each row = one query with:
# - question
# - answer (generated by your RAG system)
# - contexts (list of retrieved chunks)
# - ground_truth (optional, for answer correctness)

data = {
    "question": [
        "What color are apples?",
        "Which fruit is high in potassium?",
        "What vitamin do oranges contain?"
    ],
    "answer": [
        "Apples are red or green.",
        "Bananas are high in potassium.",
        "Oranges contain vitamin C."
    ],
    "contexts": [
        ["Apples are red or green. They grow on trees.", 
         "Oranges are orange and rich in vitamin C."],
        ["Bananas are yellow and curved. They are high in potassium.",
         "Apples grow on trees."],
        ["Oranges are orange and rich in vitamin C.",
         "Bananas are high in potassium."]
    ],
    "ground_truth": [
        "Apples are red or green.",
        "Bananas are high in potassium.",
        "Oranges contain vitamin C."
    ]
}

dataset = Dataset.from_pandas(pd.DataFrame(data))

# ==========================================
# 2. Setup evaluator LLM (use GPT-4 or any)
# ==========================================
# Replace with your OpenAI key
evaluator_llm = LangchainLLMWrapper(ChatOpenAI(model="gpt-4o", temperature=0))
evaluator_embeddings = LangchainEmbeddingsWrapper(OpenAIEmbeddings())

# ==========================================
# 3. Run evaluation
# ==========================================
result = evaluate(
    dataset=dataset,
    metrics=[
        faithfulness,        # Is answer grounded in contexts?
        answer_relevancy,    # Does answer address the question?
        context_precision,   # Of retrieved chunks, how many were needed?
        context_recall,      # Of all needed chunks, how many retrieved?
        context_relevancy    # Are retrieved chunks relevant to question?
    ],
    llm=evaluator_llm,
    embeddings=evaluator_embeddings
)

# ==========================================
# 4. View results
# ==========================================
print(result)
# Convert to DataFrame for easy reading
df_result = result.to_pandas()
print(df_result)
```

**Sample Output (values between 0-1):**

```
{
    'faithfulness': 0.95,
    'answer_relevancy': 0.92,
    'context_precision': 0.78,
    'context_recall': 0.85,
    'context_relevancy': 0.81
}
```

| question | faithfulness | answer_relevancy | context_precision | context_recall |
|----------|--------------|------------------|-------------------|----------------|
| What color are apples? | 1.0 | 0.95 | 0.5 | 1.0 |
| Which fruit is high in potassium? | 1.0 | 0.98 | 1.0 | 1.0 |
| What vitamin do oranges contain? | 0.85 | 0.83 | 0.5 | 0.5 |

**Interpretation:**
- **Faithfulness 1.0** → No hallucination.
- **Context precision 0.5** → Half of retrieved chunks were irrelevant (e.g., got orange info when asking about apples).
- **Context recall 0.5** → Missed half the needed chunks (e.g., only retrieved 1 out of 2 relevant chunks).

## Key Takeaways for Your Interview

| Metric | What it tells you | When to prioritize |
|--------|-------------------|--------------------|
| **Faithfulness** | No hallucinations | Medical, legal, finance – always #1 |
| **Context recall** | Did you find all relevant info? | When answers require multiple facts |
| **Context precision** | Are you wasting tokens on irrelevant chunks? | Cost-sensitive, low-latency systems |
| **Answer relevancy** | Is the answer on topic? | Chatbots, user-facing Q&A |
| **Hit rate / MRR** | How good is your retriever? | Debugging retrieval before generation |
